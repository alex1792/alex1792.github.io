# Gallery photos

Add your photographs to this folder using these filenames:

- `los-angeles.jpg`
- `california-coast.jpg`
- `taipei-street.jpg`
- `after-rain.jpg`
- `quiet-morning.jpg`
- `on-the-move.jpg`

For fast page loading, export images as JPG or WebP at roughly 2000–2500 px
on the longest edge. Titles, locations, categories, and alt text can be edited
in `gallery.html`.
